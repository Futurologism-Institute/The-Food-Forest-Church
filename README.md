# The Food Forest Church

**Futurologism Institute**

A living directory of **edible native plants of the United States**, organized by state, with links to extension services, universities, native-plant societies, and other sources that document what is native and edible in each place.

The aim is practical: support food forests, church and community gardens, and household resilience by pointing people to plants that belong to their bioregion.

> **Safety note:** Never eat a wild plant unless you are certain of its identification and that the part you intend to use is edible. Many edible plants have poisonous look-alikes. Consult local experts, extension agents, and multiple reliable sources. This project is educational, not a foraging manual.

## Structure

- [`INDEX.md`](INDEX.md) — links to every state + DC
- `states/` — one Markdown file per state

Each state page includes a short bioregional note, curated links that cite edible native plants, and a few example species often mentioned for the region.

## National / multi-state references

- [USDA Plants Database](https://plants.usda.gov/) — distribution and taxonomy
- [Lady Bird Johnson Wildflower Center](https://www.wildflower.org/) — native plant database (filter by state)
- [Native Plant Finder (National Wildlife Federation)](https://www.nwf.org/NativePlantFinder) — by ZIP code
- [USDA Plant Hardiness Zone Map](https://planthardiness.ars.usda.gov/)
- [Foraging Across America overview (Texas Real Food)](https://discover.texasrealfood.com/foraging/foraging-guide-for-all-50-us-states) — state-by-state starting points
